# Images Camera Club of Cebu — website

Public website for the Images Camera Club of Cebu at **https://www.imagescameraclub.com**.
Main purpose: showcase members' photographs. Some content is members-only.

## Users and roles
- **Guest (public):** gallery, member portfolios, about, public events, contact.
- **Member:** everything public plus announcements, full activity schedule, own profile and
  portfolio, contest submissions (later).
- **Administrator:** manages members, invite codes, announcements, events, galleries, featured work.

## Sign-in
- Google sign-in (optional; not every member has a Google account).
- Invite / referral codes generated by an admin (single use, expiring) → member sets a username
  and password. Admin-issued reset codes until email exists.
- Later: email verification and email password reset.

## Planned later (design data so these fit without rework)
- Guest inquiries for image usage rights, prints, and purchases (payments later, e.g. PayMongo).
- Internal contest photo submissions using the owner's StickyForms.io — ask the owner for its
  hand-off document before building this part.

## Stack (same as the owner's Dual Crest HRIS, which shares the server)
Node.js 22, Express, EJS, SQLite (better-sqlite3), passport + Google OAuth, express-session,
helmet, zod, multer, sharp for image resizing. Tests with `node --test`.

## Server
See [docs/SERVER.md](docs/SERVER.md). Served from `/srv/photoclub`, port `3001`, service
`photoclub`, via the existing Cloudflare Tunnel. Original photos are kept outside the app folder
(object storage), never in git.

## Rules for Claude
- This repository is the **Images Camera Club website** (`OWNER/photo-club` — replace with the real
  repository once created), served at `www.imagescameraclub.com` from `/srv/photoclub` on port
  `3001`, service `photoclub`.
- The same server also runs the **Dual Crest HRIS** (`/srv/hris`, port 3000, service `hris`,
  repository `apsungahid/Soju-Framework`). Never read, change, restart, deploy or push anything of
  the HRIS from this project.
- **`/deploy`** in this project means: run the tests; if they pass, commit and push this
  repository's work branch to **this repository's** `main`. GitHub Actions then deploys the club
  website only. Before pushing, check `git remote get-url origin` is this club repository; if it is
  anything else, stop and say so.
- Only `/deploy` pushes to `main`. Other pushes go to the work branch.
- Never commit `.env`, databases, uploaded photos or other local data.
- The look must be professional: photography first, generous whitespace, restrained typography,
  no stock-template feel.
